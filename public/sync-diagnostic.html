G-MedHub Sync Diagnostic Tool

This page checks whether your Supabase data is reachable and whether IndexedDB is working correctly. Fill in your Supabase URL and anon key below (the same values you set as VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY in Vercel), then click "Run Diagnostic". The results will tell you exactly which part of the data pipeline is broken.
